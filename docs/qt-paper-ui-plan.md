# Qt 淡色数学稿纸界面

当前默认桌面入口改为 PySide6/Qt。模型计算仍由现有 Python 内核完成，界面在同一个
Python 进程中调用 `ModelSpec.handler`，不启动浏览器，也不拆成前后端服务。旧 Tk
视图保留为兼容后端，历史 `ui/web` 资源不再注册到入口。

## 已落实的界面原则

- **淡色稿纸**：背景使用米白纸张、细网格和更淡的整页网格线，文字采用深灰，主色只
  用于当前模型和交互反馈。
- **单列阅读顺序**：模型说明 → 主舞台 → 状态与关键数字。控制台从右上角以悬浮抽屉
  打开，不进入页面布局，因此展开时不会挤压或改变主舞台尺寸；窗口不再永久占据左中右
  三栏，窄屏下仍然沿用同一阅读顺序。
- **两级折叠**：控制台默认收起；控制台内部的“高级选项”“批量统计”“曲线扫描”
  也默认收起。用户先看模型变化，再决定是否展开参数。
- **同一套模型契约**：Qt 通过 `spec.params` 自动生成参数控件，通过 `spec.actions` 找到
  主动作；没有专用画布的模型先使用结果舞台，不需要修改模型内核。
- **可恢复反馈**：计算错误留在状态栏，窗口不因单次参数错误退出；模型切换和返回目录
  不会清空已创建的页面。

## 渗流画布

边渗流和点渗流使用专用 Qt 画布。开放边、阻断边、节点、注水线和出口线保持纸面配色，
水团按 BFS 层使用连续色相（黄 → 青 → 紫 → 红），两端已浸润的开放边会变粗并跟随层数
变色。播放、暂停和完成按钮的文字由舞台声明：渗流显示浸润语义，生命游戏显示代际播放，
万有引力显示轨道帧回放；点击节点会用该节点作为起点重新运行一次实验。

## 继续补充的产品要求

1. **实验状态**：为每个模型保存“当前参数、随机种子、最近一次结果”和“是否展开控制台”，
   这样切换模型后可以回到原来的实验台。
2. **结果解释**：关键数字旁增加一句模型特有的解释，例如渗流明确区分贯通判据、起点判据
   和面积判据，避免把所有成功率都误称为临界值。
3. **长任务反馈**：批量统计和曲线扫描放到 Qt 工作线程，显示进度、已完成次数、取消按钮，
   并保证取消后旧结果不会覆盖新参数。
4. **可访问性**：所有图标按钮提供文字提示和键盘焦点顺序；动画提供暂停、单步和降低速度
   的选项；颜色之外再用线型、节点形状和文字表达状态。
5. **导出与复现**：提供“复制实验配置”和“导出结果摘要”，把模型 key、版本、参数、随机
   种子与时间写入文本，保证图形可以被复现。
6. **性能边界**：高分辨率 Mandelbrot 和大规模批量任务必须显示当前阶段（计算、编码、绘制）
   与耗时；默认先给低分辨率预览，再更新清晰结果。
